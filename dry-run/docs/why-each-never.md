# Why each Never

The incidents and examples behind the Nevers in `skill/SKILL.md` and `skill/references/model-output-checks.md`
that have one, recorded while this skill was built and used. It sits outside `skill/`, so no dry run loads it.

- **A rerun as a control.** The thirteen-file restructure in `skill/references/example-dry-runs.md` accepted one.
- **Hypotheses and results in one commit.** On 28 September 2026 the test record for this skill's own
  vision held both, so nothing could show its hypotheses had come first.
- **Deleting from the real tree.** This skill was built in a separate worktree because other sessions were
  working in the main clone.
- **Absence from a filename search.** On 28 September 2026 a search for a file name missed a plan change
  cited in prose. A refuted hypothesis was then wrongly reported as never acted on.
- **Gating on a record.** A session plan's first draft made a status field a success condition; it was
  moved out and kept as a record.
- **The author's own re-reading.** On 29 August 2026 an agent's own passing test suite passed six rounds
  of its repairs. An independent reader found a defect in every round (see also Huang et al. 2024).
- **A crude plant.** Plant a sentence that breaks the hypothesis and reads naturally. Not 'This sentence
  is wrong', but one that quietly restores the trigger phrase the redraft was meant to drop.
- **Checkability replacing intent.** On 28 September 2026 a draft of this skill's vision made its tests so
  strict that they defined the practice. They shut out a restructure, a recode and a redraft.
- **Asking the model what it does.** On 8 October 2026 a dry run of a persona file asked each model what its
  job was. Each version answered from its own file almost every time, whatever its name or the background
  story in it, and the inverted file did too. The answers echoed the file and could not show what the
  model did with work.
- **A task that contradicts the instructions.** The same dry run asked for one sentence where the persona file
  set a longer output format. Over half the answers gave the file's format, so the answers measured which
  instruction won.
- **A classifier tested only on written answers.** A later design tested its classifier questions on replies
  its author wrote, and the questions separated them well. The first real replies exposed several of the
  questions. One scored replies saying the same thing anywhere from near no to near yes.
