# Answer every other question

Read [`../references/questions/persona-checks.md`](../references/questions/persona-checks.md) and
[`../references/questions/persona-ratings.md`](../references/questions/persona-ratings.md) in full and answer the
persona questions. Then read
[`../references/questions/instruction-writing.md`](../references/questions/instruction-writing.md) in full and answer
those, so each set is fresh when you answer it.

Answer 'A dedicated persona' first, then the rest for each persona in the order each file gives them.

For each question marked *reading*, list every place it covers, quote each place that falls short, then score from
those quotes, so the score follows from what was found.

When a file is empty, say so and give it no score, because there is nothing to quote. When part of a file cannot be
read, review the rest and name the part skipped, because a reader would otherwise take the score to cover all of it.

Load [`../references/persona-boundaries.md`](../references/persona-boundaries.md) when `find.py` sets a file aside or
reports a persona's kind as inferred, or before a finding names the model, the harness or a hook as the cause; leave it
unloaded otherwise, because no other answer depends on it.
